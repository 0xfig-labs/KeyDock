# Privacy

KeyDock stores vault data on your device. It does not include analytics or upload vault contents as part of normal use.

The desktop app contacts GitHub Releases only when it checks for or downloads an application update. The marketing website may request public GitHub repository statistics. Those services process requests under their own privacy policies.

Activating a preset writes its mapped environment variables to a local plaintext shell cache so future shells can use them. Prefer `keydock run <preset> -- <cmd>` when command-scoped access is sufficient.

This policy describes the current preview release and will be updated before any hosted sync or team features are introduced.
